# BlindSpot Training Pipeline

## Overview

This directory contains the training framework used by the BlindSpot Occupancy Classification model.

BlindSpot is a binary classification task that predicts whether a vehicle blindspot is:

```text
FREE      = 0
OCCUPIED  = 1
```

Unlike AutoSpeed, BlindSpot does not perform object detection. The training pipeline is therefore intentionally focused on classification, model stability, and reliable validation.

# trainer_blindspot.py

## Purpose

`trainer_blindspot.py` is the main entry point for BlindSpot training and validation.

It orchestrates the complete machine-learning workflow from dataset loading to model checkpoint generation.

---

## Responsibilities

### Model Creation

Creates the BlindSpot network and moves it to the selected device.

The trainer also supports optional backbone initialization from a pretrained AutoSpeed checkpoint.

This allows BlindSpot to reuse previously learned visual features and accelerate convergence.

---

### Dataset Loading

The trainer consumes metadata generated by:

```text
parse_woodscape.py
```

and loads training samples using:

```text
load_woodscape.py
```

Expected metadata:

```text
train_metadata.json
val_metadata.json
```

---

### Training

During every iteration:

```text
Load Batch
      ↓
Forward Pass
      ↓
CrossEntropyLoss
      ↓
Backward Pass
      ↓
Optimizer Update
      ↓
EMA Update
```

---

### Validation

Validation is executed after every epoch.

The validation phase evaluates the EMA model and computes all classification metrics.

---

### Checkpointing

The trainer maintains two checkpoints:

```text
last.pt
```

Most recent training state.

```text
best.pt
```

Best-performing model according to validation F1 score.

---

### TensorBoard Logging

The trainer logs:

```text
Training Loss
Validation Loss
Accuracy
Precision
Recall
F1 Score
Learning Rate
```

for training monitoring and experiment comparison.

# Training Configuration

## Loss Function

BlindSpot is trained using:

```python
torch.nn.CrossEntropyLoss()
```

Output format:

```python
occupancy_logits.shape == (B, 2)
```

Class mapping:

```text
0 → FREE
1 → OCCUPIED
```

---

## Optimizer

BlindSpot V1 uses:

```python
torch.optim.SGD(
    momentum=0.937,
    nesterov=True,
)
```

### Why SGD?

The objective is consistency with other perception projects while providing:

- Stable optimization
- Predictable convergence
- Easier comparison with AutoSpeed and AutoSteer

---

## Learning Rate Scheduler

BlindSpot V1 uses:

```text
LinearLR
```

Schedule:

```text
Warmup
    ↓
Linear Decay
```

A cosine scheduler is available for future experimentation but is not used in the baseline configuration.

---

## EMA

Training maintains an Exponential Moving Average (EMA) of model parameters.

### Why EMA?

EMA typically provides:

- More stable validation results
- Better generalization
- More reliable model selection

Validation and checkpoint saving use EMA weights.

---

# Model Selection

## Primary Metric

The best model is selected using:

```text
Validation F1 Score
```

rather than accuracy.

### Why F1?

F1 balances:

```text
Precision
Recall
```

and provides a more reliable view of performance when class frequencies are not perfectly balanced.

---

## Confusion Matrix Definitions

```text
TP
```

Occupied blindspot correctly predicted as occupied.

```text
TN
```

Free blindspot correctly predicted as free.

```text
FP
```

Free blindspot incorrectly predicted as occupied.

```text
FN
```

Occupied blindspot incorrectly predicted as free.

### Safety Note

False negatives are particularly important because they correspond to occupied blindspots that the model failed to detect.

# blindspot_util.py

## Purpose

`blindspot_util.py` contains reusable utilities shared across the training pipeline.

The utilities are intentionally lightweight because BlindSpot is a classification problem.

Unlike AutoSpeed, BlindSpot does not require:

```text
Anchors
NMS
IoU Computation
Detection Losses
mAP Calculation
```

---

## Available Utilities

### Reproducibility

```python
setup_seed()
```

Configures deterministic random seeds for:

- Python
- NumPy
- PyTorch

---

### Runtime Configuration

```python
setup_multi_processes()
```

Configures the training environment for efficient multiprocessing and dataloader execution.

---

### Metric Tracking

```python
AverageMeter
```

Maintains running averages for metrics such as:

- Training loss
- Validation loss
- Accuracy
- F1 score

---

### Learning Rate Schedulers

```python
LinearLR
CosineLR
```

Provide warmup and decay scheduling strategies.

BlindSpot V1 uses `LinearLR`.

---

### Exponential Moving Average

```python
EMA
```

Maintains smoothed model weights for validation and checkpoint generation.

---

### Optimizer Parameter Grouping

```python
set_params()
```

Creates optimizer parameter groups with appropriate weight-decay handling.

---

### Checkpoint Cleanup

```python
strip_optimizer()
```

Removes training-specific information from checkpoints and prepares models for deployment.

---

### Classification Metrics

```python
compute_confusion_matrix()
compute_classification_metrics()
```

Provide validation statistics used during training and model selection.

# Design Principles

BlindSpot V1 prioritizes:

- Simple and reliable classification
- Temporal occupancy prediction
- Consistent evaluation
- Strong validation practices
- Lightweight training infrastructure
- Compatibility with AutoSpeed weight transfer

The objective is to establish a robust baseline before introducing more advanced temporal reasoning, class-balancing strategies, or architectural extensions.
